# Task 05 – Time-Series Forecasting with ARIMA

This project analyzes daily demand data and builds a 30-day forecast using an ARIMA baseline model.

## Files
- `Time_Series_Forecasting.ipynb` – Jupyter Notebook containing data preparation, time-series decomposition, ADF stationarity test, ARIMA training, MAPE/RMSE evaluation, and a 30-day forecast.

## Dataset
Download the **Daily demand time series** CSV file from the RobTech Academy task page and place it in the same folder as the notebook. The notebook expects the filename:

`Daily demand time series.csv`

If the downloaded file has a different name, update `file_path` in the notebook.

## Run
1. Install the packages listed in `requirements.txt`.
2. Open the notebook in Jupyter Notebook or JupyterLab.
3. Run all cells from top to bottom.
4. Save the notebook with its executed outputs before submitting.

Note: Forecast values and evaluation metrics are generated from the supplied dataset when the notebook is run. They are not pre-filled.
